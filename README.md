# 🌤 Real-Time Weather Forecast Web Application

## 📌 Project Overview

The Real-Time Weather Forecast Web Application is a responsive web application that allows users to check the current weather and a 5-day weather forecast for any city using the OpenWeatherMap API. It provides real-time weather information through a simple and attractive user interface.

---

## 🚀 Features

- Search weather by city name
- Display current temperature
- Weather description
- Weather icon
- Humidity
- Wind speed
- Feels like temperature
- Atmospheric pressure
- 5-day weather forecast
- Responsive design
- User-friendly interface

## ⚙️ How to Run

1. Download or clone the project.
2. Open the project in Visual Studio Code.
3. Replace `YOUR_API_KEY` in `script.js` with your OpenWeatherMap API key.
4. Install the Live Server extension.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. Enter a city name and click **Search**.

---

## 🌐 API Used

OpenWeatherMap API

Current Weather API:
https://api.openweathermap.org/data/2.5/weather

5-Day Forecast API:
https://api.openweathermap.org/data/2.5/forecast
